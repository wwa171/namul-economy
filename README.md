# TShock RPG Core (namul-economy)

최신 TShock(v6.2.1 / Terraria 1.4.5.8, .NET 9.0) 기반의 **통합 RPG 코어 플러그인**입니다.  
경제, 경험치/레벨업, 직업/스탯 분배 시스템, 일일 몬스터 토벌 퀘스트, 인게임 상점 시스템, 스폰 거리 비례 몬스터 스케일링을 하나의 완전한 RPG 프레임워크로 제공합니다.

---

## 🌟 핵심 시스템 구성

### 1. 3중 독립 SQLite 분리 저장 (`tshock/economy_exp/`)
데이터 성격에 따라 DB 파일이 완전히 독립되어 있어, 시즌 리셋 및 백업 관리가 매우 쉽습니다.
- **`economy_data.sqlite`**: 유저 골드 잔액, 거래 내역
- **`exp_data.sqlite`**: 유저 레벨, 누적 경험치
- **`rpg_data.sqlite`**: 직업, 스탯 포인트(힘/민/지/체), 진행 중인 퀘스트 데이터

---

### 2. RPG 직업 & 스탯 시스템
- **전직 가능한 직업**: `초보자`, `전사`, `궁수`, `마법사`, `소환사`
- **스탯 포인트 보너스**: 레벨업할 때마다 **스탯 포인트 5개** 자동 지급!
- **스탯 효과**:
  - 💪 **힘 (STR)**: 공격 데미지 강화 (+1.5% / pt)
  - 🏹 **민첩 (DEX)**: 공격 데미지 및 기동성 강화 (+1.5% / pt)
  - 🔮 **지능 (INT)**: 마법/소환 데미지 강화 (+1.5% / pt)
  - ❤️ **체력 (VIT)**: 생존력 강화
  - `/스탯초기화` 명령어로 언제든지 스탯 포인트 100% 반환 및 재투자 가능

---

### 3. 실시간 데미지 비례 보상 & 몬스터 커스텀 설정
- 몬스터에게 **실제 입힌 데미지에 비례**하여 경험치와 골드를 실시간으로 획득합니다.
- **서버 측 강제 타격(StrikeNPC) + 패킷 동기화(Packet 28)** 기법을 적용하여 스탯 보너스 데미지가 클라이언트 화면에 정확히 팝업되며 체력바가 실시간 갱신됩니다.
- **타겟 더미(Target Dummy, NetID: 488) 완전 차단** 어뷰징 방지
- `config.json`을 통해 몬스터별 개별 배율 및 토벌 추가 보너스 설정 가능
- 보스 몬스터 토벌 시 서버 전체 축하 공지

---

### 4. 스폰 지점 거리 비례 몬스터 동적 강화 (Distance Scaling)
- 스폰 지점(`Main.spawnTileX`, `Main.spawnTileY`)에서 멀어질수록 몬스터의 체력과 공격력이 점진적 강화 (보스 제외)
- 타일 단위 안전지대 반경, 스텝당 증가율, 최대 배율, 거리 계산 모드(Euclidean / HorizontalOnly / Taxicab) 완벽 커스텀 지원
- 거리로 강해진 몬스터 처치 시 보상 경험치/골드 동적 증가 연동

---

### 5. 일일 몬스터 토벌 퀘스트 시스템
- 플레이어 레벨대에 맞는 몬스터 토벌 퀘스트를 랜덤 배정
  - Lv. 1~9: 슬라임, 좀비, 악마의 눈
  - Lv. 10~24: 스켈레톤, 동굴 박쥐, 영혼을 먹는 자
  - Lv. 25~49: 호넷, 맨 이터, 지옥 박쥐 등
  - Lv. 50+: 하드모드 몬스터
- 퀘스트 목표 달성 시 대량의 보너스 경험치와 골드 즉시 지급!

---

### 6. 인게임 상점 시스템 (`shop.json`)
- 카테고리별 아이템 구매 및 인벤토리 아이템 판매 기능 지원
- 서버 설정 파일(`shop.json`)에서 손쉽게 아이템 추가/수정 가능

---

### 7. 다국어 GUI 설정 에디터 (`NamulRpgConfigTool.exe`)
- 한국어(KO) / 영어(EN) 원클릭 전환 지원
- 복잡한 JSON 편집 없이 시각적인 UI에서 경제/경험치/거리 강화 파라미터를 즉시 편집하고 저장 가능
- .NET 9.0 런타임 공유 방식으로 용량 **877 KB** 초경량화

---

## 🎮 전체 인게임 명령어 안내

### 💰 경제
- `/돈` 또는 `/bal`, `/balance` [유저이름]: 본인/대상 잔액 확인
- `/송금` 또는 `/pay` [받는사람] [금액]: 다른 유저에게 골드 송금
- `/돈지급` 또는 `/givemoney` [유저이름] [금액]: (관리자) 골드 강제 지급

### ⭐ 경험치 & 레벨
- `/레벨` 또는 `/경험치`, `/lvl`, `/level`, `/exp` [유저이름]: 현재 레벨 및 진행도
- `/랭킹` 또는 `/순위`, `/top`, `/rank`: 서버 레벨 랭킹 TOP 10 명예의 전당
- `/경험치지급` [유저이름] [수량]: (관리자) 경험치 지급
- `/레벨설정` [유저이름] [레벨]: (관리자) 레벨 강제 설정

### 🗡️ RPG 직업 & 스탯
- `/직업` [전사|궁수|마법사|소환사]: 현재 직업 확인 및 전직
- `/스탯` 또는 `/정보`, `/status`, `/stat`: 캐릭터 RPG 스탯 및 미분배 포인트 확인
- `/스탯분배` [힘|민첩|지능|체력] [수량]: 스탯에 포인트 투자
- `/스탯초기화`: 모든 스탯을 초기화하고 포인트를 반환받음

### 📜 일일 퀘스트
- `/퀘스트`: 현재 진행 중인 토벌 퀘스트 목표 확인
- `/퀘스트 받기`: 내 레벨에 맞는 새로운 일일 토벌 퀘스트 수락
- `/퀘스트 포기`: 진행 중인 퀘스트 취소

### 🏪 상점
- `/상점`: 판매 중인 아이템 목록 및 가격 확인
- `/구매` [아이템이름] [수량]: 상점에서 아이템 구매 (인벤토리로 자동 지급)
- `/판매` [아이템이름] [수량]: 인벤토리 아이템을 상점에 판매하고 골드 정산

---

## 🔨 빌드 및 적용 방법

1. 프로젝트 폴더에서 빌드:
   ```powershell
   dotnet build -c Release
   ```
2. 생성된 `bin/Release/net9.0/TShockEconomyExp.dll`을 TShock 서버의 `ServerPlugins/` 폴더에 복사
3. 서버 실행 후 `tshock/economy_exp/` 폴더 내의 `config.json` 및 `shop.json`으로 밸런스 조정
